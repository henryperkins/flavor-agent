# Flavor Agent v0.1.2

Prepared dependency-security candidate. It supersedes the [v0.1.1 candidate](v0.1.1.md), which was tagged and drafted but never published or deployed. Every v0.1.1 change is included unchanged. See the [validation record](../validation/2026-10-08-v0.1.2-release-validation.md).

## Changes from v0.1.1

- The AI Activity admin bundle (`build/activity-log.js`) now ships colord 2.9.4, which parses color strings in linear time ([GHSA-2wm5-q62r-hmrv](https://github.com/advisories/GHSA-2wm5-q62r-hmrv)). The prebuilt DataViews bundle reaches colord through its `color` field type, color picker and readability helper. None of those is reachable from AI Activity, whose fields are media, text, date and datetime, so v0.1.1 bundled the old parser without using it.
- Apart from that bundle and its `activity-log.asset.php` version hash, every built asset is byte-identical to v0.1.1.
- Other locked packages moved to patched releases within their declared ranges, including moment, nanoid, PostCSS, source-map-js, fast-uri, proxy-addr, shell-quote, tinypool, websocket-driver, tar, hono and brace-expansion. None of them ships in the plugin ZIP. Moment reaches the plugin only through the externalized `wp-date` script, and the others are build or development tooling.
- The change is lockfile-only: `package.json` changes only its version.
- The version is 0.1.2. The plugin header and `FLAVOR_AGENT_VERSION` change; no PHP logic, editor or admin source changed.

## Open boundaries

- Against the October 7 Dependabot snapshot, 14 of 78 alerts are projected to remain, all development-scoped:
  - Four need a major `@wordpress/scripts` upgrade: linkify-it, two markdown-it and minimatch.
  - postcss-selector-parser 6.x has no fixed release in the 6.x range that cssnano 6 and postcss-calc 9 require.
  - Six are Lighthouse's pinned `@opentelemetry` instrumentations.
  - Three have no fixed release: two extract-zip and one sprintf-js.
- `npm audit` still lists high-severity entries on development-only chains, including basic-ftp and braces. It also flags several direct `@wordpress/*` dependencies through those chains, although none of that code ships. Dependabot recomputes alerts only after the lockfile reaches the default branch.
- A block recommendation requested before the editor's pattern catalog finishes loading can be marked stale even though nothing changed. This affects fresh sites with structural actions enabled and predates 0.1.2. Apply stays blocked until Refresh, which resolves it.
- Developer Docs corpus settlement still blocks release. The latest full desired-key census, on October 7, had pending keys and five errors. Each of the five errored items received one accepted INDEX retry, without recovery. A Cloudflare support escalation is open. Settlement and the unchanged default freshness check must pass before release.
- Production package replacement, live verification and the post-cutover outcome cohort remain pending. Automated source deployment stays disabled.

Install the built plugin ZIP through the WordPress upload/update flow. Avoid plugin deletion, which can remove saved plugin data. Manual release builds set `COMPOSER_ROOT_VERSION=0.1.2`.
