# Flavor Agent v0.1.2

Prepared dependency-security candidate. It supersedes the [v0.1.1 candidate](v0.1.1.md), which was tagged and drafted but never published or deployed. Every v0.1.1 change is included unchanged.

## Changes from v0.1.1

- The AI Activity admin bundle (`build/activity-log.js`) now ships colord 2.9.4, which parses color strings in linear time ([GHSA-2wm5-q62r-hmrv](https://github.com/advisories/GHSA-2wm5-q62r-hmrv)). DataViews uses colord only for `color` fields, and AI Activity defines none, so v0.1.1 bundled the old parser without using it. No other built asset changed: the editor, settings, and stylesheet outputs are byte-identical to v0.1.1.
- Locked build and test tooling moved to patched releases within their declared ranges, including moment, nanoid, PostCSS, source-map-js, proxy-addr, shell-quote, tinypool, websocket-driver, tar, fast-uri, hono, and brace-expansion. None of these ship in the plugin ZIP. The change is lockfile-only; `package.json` changes only its version.
- The version is 0.1.2. No PHP, editor, or admin source changed.

## Open boundaries

- Against the October 7 Dependabot snapshot, 14 of 78 alerts are projected to remain, all development-scoped. Five need a major `@wordpress/scripts` upgrade (linkify-it, two markdown-it, minimatch, and the 6.x postcss-selector-parser). Six are Lighthouse's pinned `@opentelemetry` instrumentations. Three have no fixed release (two extract-zip, one sprintf-js). `npm audit` also reports basic-ftp, braces, and `@opentelemetry/core` on the same development-only chains. Dependabot recomputes alerts only after the lockfile reaches the default branch.
- Developer Docs corpus settlement is still blocked. Five managed indexing items remain in error after one accepted retry each, and a Cloudflare support escalation is open. Settlement and the unchanged default freshness check must pass before release.
- Production package replacement, live verification, and the post-cutover outcome cohort remain pending. Automated source deployment stays disabled.

Install the built plugin ZIP through the WordPress upload/update flow. Avoid plugin deletion, which can remove saved plugin data. Manual release builds set `COMPOSER_ROOT_VERSION=0.1.2`.
