Prepared compatibility candidate based on the current development checkout. It
includes the dependency remediation from [v0.1.2](v0.1.2.md), the subsequently
merged UI/apply fixes, and the Guidelines/catalog follow-up. The
[validation record](../validation/2026-10-08-v0.1.3-release-validation.md) owns

disabled-grounding implementation are uncommitted working-tree changes.

## Changes

- Temporarily disable external Developer Docs by default, including live
  searches, cached snippets, direct docs lookup, and plugin validation. Show
  intentional disabled status while retaining Guidelines, optional roadmap
  guidance, private pattern retrieval, static ranking, and apply/undo safety.
  Preserve saved docs settings and old runtime observations; isolate future
  qualified restoration from pre-suspension caches.
- Read AI 1.4.0's shared `wp_knowledge` Guidelines: published scope/block rows,
  the `wp_knowledge_type=guideline` taxonomy boundary, settings status, export,
  block notes, and guideline-version attribution. Older singleton storage and
  local options retain their compatibility paths.
- Defer structural block fetch and stale-result Refresh until core finishes
  its server pattern catalog resolution. Local patterns arriving first do not
  release the gate. Empty/failed completion releases it; a stalled or missing
  signal has a 20-second fallback. Later catalog changes retain normal
  freshness and apply checks.
- Honor AI 1.4.0's retired master toggle while preserving per-feature controls.
  Native fixtures now leave the deleted option absent; older AI fixtures still
  enable the supported master toggle.
- Include the [seven UI/apply hardening fixes](../validation/2026-10-08-ui-theme-review-fixes.md):
  reviewed target identity, asynchronous Apply drift, insertion target drift,
  duplicate pattern insertion, preserved prompt drafts, resumed sync polling,
  and contextual Activity decision permissions.
- Regenerate translations for current source strings and bound the browser
  welcome-guide dismissal helper.
