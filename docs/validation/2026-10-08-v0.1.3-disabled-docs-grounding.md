# v0.1.3 without external Developer Docs grounding — 2026-10-08

## Authorized scope and source boundary

The maintainer explicitly approved: "approve and implement v0.1.3 without
external docs grounding". This changes the release's feature scope after the
[bounded corpus investigation](2026-10-08-corpus-recovery.md). It does not waive
or pass the failed corpus settlement and freshness checks. Those checks remain
requirements before restoring external grounding.

The implementation is an uncommitted working-tree change on `master`, based
on `0913173ca2f44aa5f3daa2d23e5259445fdd292f`. No clean-checkout, immutable
candidate, or exact-tag proof is implied. Commit/push, publication, production
replacement, and live verification remain separate actions.

## Behavior

- External Developer Docs are disabled by default through
  `AISearchClient::is_enabled()` and the default-false
  `flavor_agent_docs_grounding_enabled` filter. No settings toggle enables it.
- The shared client rejects direct docs lookup and configuration validation
  with `docs_grounding_disabled` before transport. Recommendation and
  signature paths bypass cached and live docs and report intentional disabled
  diagnostics, rather than an empty-query/cache-miss/transport-error state.
- Runtime and settings synthesize `disabled` without deleting earlier backend
  observations. Editor notices state that grounding is temporarily disabled
  and suggestions remain available. Unrelated settings saves preserve the
  saved docs result limit while its control is hidden.
- Guidelines, optional core-roadmap guidance, private pattern retrieval, static
  ranking, and apply/undo contracts are retained. Removing previously attached
  docs content changes the content fingerprint and requires normal refresh;
  diagnostic-only changes do not invalidate content.
- Docs cache schema 4 isolates any future separately approved restoration from
  schema-3 entries. Controlled enabled-path tests retain coverage, while the
  release default and native probes must exercise disabled behavior.
